# Безопасность

## Сообщить об уязвимости

Не открывайте публичный issue. Используйте приватный отчёт GitHub:
**Security → Report a vulnerability** в репозитории `swensi17/skmate-iptv`. Ответ в течение 7 дней.

## Что защищаем

- **Обновления.** Приложение берёт APK только из релизов этого репозитория, по HTTPS. Перед
  установкой проверяется, что файл читается как пакет этого приложения; система Android сама
  отказывает в установке APK с другой подписью. Каждый релиз публикуется с `SHA256SUMS.txt`, а CI
  сверяет подпись APK с отпечатком ключа проекта.
- **Ключ подписи** один на всё время жизни проекта. Он хранится только в GitHub Secrets и в двух
  независимых копиях вне репозитория. В git, логах и отчётах его нет.
- **Данные пользователя** (плейлисты, логины провайдера, история) остаются на устройстве: нет
  аккаунта, облачной синхронизации и телеметрии. Отчёты диагностики вырезают пароли и ссылки с логинами.
- **Зависимости** проходят проверку лицензий; обновления зависимостей приходят pull request'ами
  Dependabot и проходят тот же CI.

## Поддерживаемые версии

Исправления выходят только для последнего релиза.
