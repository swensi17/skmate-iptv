# SkMate IPTV для Windows

Веб-версия плеера (`../web`, та же сборка, что на LG и Samsung) в своём окне Windows: установщик с иконкой sk, ярлыки на рабочем столе и в «Пуске», обновление из релизов GitHub.

- **Пульт = клавиатура:** стрелки, Enter = OK, Esc = «Назад». F11 или Alt+Enter: полный экран.
- **Любые провайдеры:** окно читает плейлисты и телегиды с серверов без CORS-заголовков, чего не может обычный браузер.
- **Обновления:** через 5 секунд после запуска и каждые 6 часов приложение смотрит последний релиз, скачивает новую версию в фоне и спрашивает «Установить / Позже». «Позже» ставит её при закрытии. Плейлисты и настройки сохраняются.
- **Один экземпляр:** второй запуск выводит вперёд уже открытое окно.

## Сборка

```bash
cd web && npm ci && npm run build
cd ../desktop && npm ci
npm start   # окно для проверки
npm run dist   # dist/SkMate-IPTV-Setup-X.Y.Z.exe, latest.yml, .blockmap
```

На macOS `npm run dist` сам скачивает Wine, чтобы вписать иконку в exe. В релиз установщик собирает задание `desktop` в `.github/workflows/release.yml` на Windows и прикладывает его вместе с `latest.yml`, по которому установленные копии находят обновление.

Установщик не подписан сертификатом: при первом запуске Windows SmartScreen покажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
