# История разработки SkMate IPTV

Путь от первой альфа-сборки до 2.0. Каждый этап соответствует настоящим коммитам в `main`, полный список: `git log`. Подробности по пунктам в [CHANGELOG.md](../CHANGELOG.md).

## Альфа: 0.0.1 – 0.0.3 (28 октября 2026)

Первая сборка под своим именем и ключом подписи, затем всё, что нужно для приставки.

- Первая сборка SkMate IPTV: название, значок, баннер Android TV, подпись APK, обновления из своего репозитория.
- Проверочный выпуск поверх первой версии: данные сохраняются при обновлении.
- Автообновление при запуске, подборки из M3U (`#EXTGRP`), боковое меню значками.
- Настройки панелью справа, тёмная тема.

## Бета: плеер и оформление (29 октября)

- Светлая тема и круглые панели, плеер в стиле ТВ-приставок с отсчётом и превью.
- Быстрое превью каналов, подразделы настроек, резервные копии.
- Режим для слабых ТВ, единое плоское серое выделение, полный экран без анимации.

## 0.1.0: один движок и порядок в проекте (30 октября)

- Плеер на libVLC для предпросмотра и полного экрана; убраны настройки старых движков.
- Плавные переходы одной настройкой для всего интерфейса, автообновление с уведомлениями.
- Страница «О приложении», README на трёх языках, проверка VirusTotal.
- Ядро и libmpv в одном репозитории, сборка без токенов, проверки CI.
- Аудит интерфейса: единая форма фокуса, уведомления одной стопкой в правом верхнем углу.

## Дорога к 2.0 (30 – 31 октября)

**Поиск и каталог.** Умный поиск по раскладкам, транслиту и опечаткам, новый экран результатов, экран спорта с поиском и фильтрами, сортировка каналов, подборки «Сейчас идёт», «Починить телегид», чистка повторяющихся ссылок.

**Надёжность воспроизведения.** Зеркала каналов, таймаут открытия и исправление ANR на мёртвом канале, понятные экраны ошибок, буфер, который растёт при слабой сети, напоминания над любым экраном, сквозная проверка резервной копии.

**Интерфейс.** Картинка в картинке, один тёмный плеер, нижняя панель с подписями, плавное открытие телегида, мастер с удалённой настройкой, единые квадратные кнопки, значок неба по времени суток, анимации, которые подстраиваются под устройство, окно про чат в Telegram, тема по системе, уведомления-«шторка».

**Документы и сборка.** Сравнение с другими IPTV-плеерами (таблица на 30 возможностей), `llms.txt`, заметки релиза, проверки, которые не отменяются на `main`, и скрипт `scripts/pre-push-check.sh`.
