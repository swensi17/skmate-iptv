# Одинаково на всех платформах

**Правило проекта.** Всё, что умеет SkMate на Android TV, должно так же работать на Windows, LG webOS и Samsung Tizen: тот же смысл кнопок, те же правила, тот же вид, что на Android TV. Новая функция не считается готовой, пока она есть везде, или пока в таблице ниже не написано, почему на какой-то платформе её сделать нельзя.

Как работаем:

1. **По одному этапу.** Этап заканчивается только тогда, когда функция проверена тестами и вживую.
2. **Одна логика.** Правила переносятся из Android-ядра (`engine/core`) в веб-ядро (`web/packages/core`) вместе с их тестами, случай за случаем, чтобы обе платформы отвечали одинаково. Windows, LG и Samsung работают на одной веб-сборке, поэтому три платформы получают функцию сразу.
3. **Проверка.** Каждый этап проходит:
   - unit-тесты (`npm run check` в `web/`);
   - живую проверку в браузере на тестовом плейлисте с пультом (стрелки, OK, «Назад»);
   - для Windows дополнительно проверку в оболочке Electron (`SKMATE_SMOKE=1`).
4. **Честная таблица.** В README отметка ✅ ставится только после проверки. Если функция только показывается, но не работает, ставится ❌.

## Этапы

| # | Что | Android TV | Windows | LG, Samsung | Состояние |
|---|---|:---:|:---:|:---:|---|
| 1 | Архив (catch-up): передача из прошлого из телегида и поиска, перемотка ±30 с, «В эфир» | ✅ | ✅ | ✅ | готово: [`catchup.ts`](../web/packages/core/src/catchup.ts) с тестами, перенесёнными с Android |
| 2 | Перемотка эфира (таймшифт): пауза, ±30 с, «с начала», «в эфир» | ✅ | ✅ | ✅ | готово: [`timeshift.ts`](../web/packages/core/src/timeshift.ts) с тестами. Буфер — окно перемотки потока; где встроенный движок его не даёт, поток переоткрывается в hls.js на нужном отставании |
| 3 | PIN на профиль и детский профиль (скрывает категории 18+) | ✅ | ✅ | ✅ | готово: [`parental.ts`](../web/packages/core/src/parental.ts) с тестами Android-классификатора; PIN хранится так же, как на Android (`соль:sha256`) |
| 4 | Напоминания о передачах: спрашивать, переключать, только уведомлять; за 0, 1 или 5 минут | ✅ | ✅ | ✅ | готово: [`reminders.ts`](../web/packages/core/src/reminders.ts) с тестами Android |
| 5 | Языки интерфейса: все 23 языка Android | ✅ | ✅ | ✅ | готово: [`i18n/`](../web/apps/tv/src/i18n) с проверкой полноты; язык грузится отдельным файлом только при выборе. Осталось: зеркальная раскладка экрана для арабского (как на Android), сейчас справа налево идёт только текст; вычитка переводов носителями |
| 6 | Плейлист из файла | ✅ | ✅ | ❌ | готово для Windows и браузера: файл хранится на устройстве (IndexedDB). В браузере LG и Samsung нет окна выбора файла: туда плейлист придёт с телефона (этап 9) |
| 7 | Картинка в картинке, внешний плеер (VLC, mpv), запись эфира | ✅ | ✅ | ❌ | готово для Windows: [`recorder.cjs`](../desktop/recorder.cjs) с тестами (HLS по сегментам, лучший вариант качества, до конца передачи), запуск VLC/mpv с заголовками провайдера и откатом на встроенный плеер, «Мини» через Picture-in-Picture. На LG и Samsung браузер этого не позволяет |
| 8 | Stalker / Ministra (MAC-адрес) | ✅ | ✅ | ❌ | готово для Windows: [`stalker.cjs`](../desktop/stalker.cjs) с тестами из Android. Программа говорит с порталом заголовками MAG и отдаёт странице обычный M3U, телегид XMLTV и адреса каналов на 127.0.0.1; канал при открытии получает свежую ссылку `create_link`, архив — через таблицу программ портала. Фильмы и сериалы портала — вместе с разделом фильмов веб-версии. На LG и Samsung браузер не ставит заголовок Cookie |
| 9 | Плейлист с телефона по QR, перенос на другой телевизор по Wi-Fi | ✅ | ✅ | ❌ | готово для Windows: [`companion.cjs`](../desktop/companion.cjs) с тестами из Android — тот же протокол, PIN и пути, страница для телефона на языке программы; перенос между компьютерами со SkMate по адресу и PIN. Осталось: автопоиск устройств (mDNS, как на Android) и перенос между Windows и Android TV (у Android своя зашифрованная копия). На LG и Samsung браузер не открывает сервер: нужен способ без него |
| 10 | Фильмы и сериалы (VOD) из Xtream и Stalker | ✅ | ❌ | ❌ | следующий: раздел фильмов и сериалов в веб-версии, для всех трёх платформ |
| 11 | Мультивид: несколько каналов на одном экране | ✅ | ❌ | ❌ | в плане; на LG и Samsung упирается в число одновременных декодеров телевизора |

Ограничения платформ, а не наша недоработка: веб-приложение на LG и Samsung не может само открыть сетевой сервер, записывать файлы на диск и выставлять запрещённые браузером заголовки (`Cookie` для Stalker). Если такую функцию нельзя сделать на какой-то платформе, это пишется здесь и в README с причиной, а не прячется.
