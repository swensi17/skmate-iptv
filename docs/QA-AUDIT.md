# Аудит качества SkMate IPTV

Главный документ ночной проверки (старт 2026-10-30). Цель: приложение работает стабильно от и до, без визуальных багов, без дыр в безопасности, не нагружает телевизор. Каждый пункт ниже проверяется, находки записываются, исправления идут отдельными короткими коммитами.

## Кто за что отвечает

| Направление | Сессия | Файл с находками |
|---|---|---|
| Функции и стабильность (плеер, плейлисты, EPG, поиск, обновления, настройки) | функционал | [qa/function.md](qa/function.md) |
| Интерфейс и визуальные баги (фокус, анимации, темы, мини-окно, подтверждения) | ui дизайнер | [qa/ui.md](qa/ui.md) |
| Безопасность и баги (утечки, права, сеть, хранение, зависимости) | безопасность и баги | [qa/security.md](qa/security.md) |

Правила для всех:
- Каждая сессия работает в своём git worktree и своей ветке, в `main` попадает короткими коммитами после проверки (`git pull --rebase`, сборка, тесты). Двое не правят один файл одновременно.
- Находка записывается в свой файл: что, где (файл:строка), как воспроизвести, серьёзность, статус (найдено, исправлено, проверено).
- Исправление без проверки не считается готовым: сборка, юнит-тесты, на эмуляторе (`skmate_tv`) или на телевизоре сценарий пройден.
- Коммит: одна строка, по-русски, строчными, без `Co-Authored-By`. Секреты и ключи не коммитить.
- Тег и релиз только по слову «релиз» от владельца.

## Серьёзность

- **S1** потеря данных, утечка, падение, нельзя смотреть канал.
- **S2** зависание, заметный лаг, сломанная функция, сломанный фокус.
- **S3** мелкий визуальный или поведенческий недочёт.
- **S4** улучшение, чего не хватает.

## Чек-лист

### Просмотр (live)
- [ ] Холодный старт канала, время до картинки (цель до 3 с на нормальном потоке).
- [ ] Переключение каналов подряд (быстро, 50 раз): нет чёрного экрана, повторов куска, утечки памяти.
- [ ] Обрыв сети и возврат: переподключение, понятное сообщение.
- [ ] Поток без IDR, 576i, смена кодека: нет «2x2».
- [ ] Предпросмотр в списке не перезагружается при открытии меню и настроек.
- [ ] Мини-окно (картинка в картинке): открытие, закрытие, фокус, возврат в полный экран.
- [ ] Только звук: фон, уведомление, остановка.
- [ ] Звук, субтитры, дорожки, соотношение сторон, скорость.
- [ ] Родительский контроль, PIN, закрытые каналы.

### Источники и данные
- [ ] M3U (файл, ссылка, QR с телефона), Xtream, Stalker: добавление, ошибка, повтор, удаление с подтверждением.
- [ ] Большие плейлисты (50 тыс. записей): скорость импорта, память, прокрутка.
- [ ] Программа передач (XMLTV): связка с каналами, обновление, сдвиг часового пояса.
- [ ] Избранное, история, продолжить просмотр, резервные копии и восстановление.
- [ ] Поиск: скорость, пустой результат, раскладки.

### Интерфейс
- [ ] Фокус пультом везде: нет потери, нет тупиков, одна форма выделения, углы 4 px.
- [ ] Серые плашки, тёмная и светлая темы, нет белых вспышек.
- [ ] Анимации: «Плавные переходы» включает и выключает все, без дёргания.
- [ ] Подтверждения для опасных действий (удаление, сброс, выход).
- [ ] Пустые состояния, ошибки, загрузка: у каждого экрана есть.
- [ ] Языки (русский, узбекский, английский, китайский): нет обрезанного текста, нет «хардкода».
- [ ] Крупный шрифт и разные размеры экрана (720p, 1080p, 4K).

### Обновления и уведомления
- [ ] Автообновление: проверка, скачивание, установка, отказ, повтор, нет сети.
- [ ] Проверка подписи и суммы SHA-256 перед установкой.
- [ ] Уведомления в правом верхнем углу стопкой, не перекрывают управление.

### Производительность и нагрузка на ТВ
- [ ] Память (RAM) после 1 часа просмотра и 100 переключений: нет роста.
- [ ] Процессор и температура в простое и на воспроизведении.
- [ ] Диск и запись: размер базы, кэш, очистка.
- [ ] Время холодного старта приложения (цель до 2 с на Haier), baseline profile.
- [ ] Размер APK, лишние зависимости и библиотеки.
- [ ] Фоновые задачи (WorkManager): не будят устройство зря.

### Безопасность
- [ ] Секреты: нет ключей и паролей в коде, истории git, ресурсах и логах.
- [ ] Сеть: HTTPS там, где возможно, `cleartextTraffic` только для потоков, проверка сертификатов, таймауты.
- [ ] Данные источников (логин, пароль Xtream): шифрованное хранение, маскирование в логах и резервных копиях.
- [ ] Компоненты в манифесте: `exported`, права, deep links, широковещательные приёмники.
- [ ] Ссылки и ввод: проверка адресов, XML и M3U парсеры устойчивы к мусору и огромным файлам.
- [ ] Обновление: загрузка только с `github.com/swensi17/skmate-iptv`, проверка подписи.
- [ ] Резервные копии: не раскрывают пароли, `allowBackup` обоснован.
- [ ] Зависимости и лицензии: известные уязвимости, `THIRD_PARTY_LICENSES.md` актуален.
- [ ] Логи: нет ссылок с токенами, нет персональных данных.
- [ ] Защита ветки `main`, секреты GitHub, права workflow минимальные.

### Сборка и репозиторий
- [ ] `build`, `engine`, `i18n` workflow зелёные, релиз собирается из чистого клона.
- [ ] `README` на трёх языках соответствует приложению, раздел «Безопасность» с актуальными суммами.
- [ ] `CHANGELOG.md` ведётся.
