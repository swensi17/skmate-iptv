## SkMate IPTV 2.2

Теперь и на компьютере: SkMate IPTV для Windows с установщиком и автообновлением. Веб-версия научилась Xtream Codes.

### Windows
- Установщик `SkMate-IPTV-Setup-2.2.0.exe`: выбор папки, ярлыки на рабочем столе и в «Пуске», иконка sk.
- Внутри тот же плеер, что на LG и Samsung: каналы, поиск в любой раскладке, телегид, спорт, профили, избранное.
- Управление с клавиатуры как с пульта: стрелки, Enter = OK, Esc = «Назад». F11 или Alt+Enter: полный экран.
- Плейлисты и телегиды открываются с любых серверов, без ограничений браузера.
- Обновления сами: проверка при запуске и каждые 6 часов, загрузка в фоне, затем окно «Установить / Позже». Плейлисты и настройки сохраняются.
- Установщик не подписан сертификатом: при первом запуске Windows покажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

### Веб-версия (LG webOS, Samsung Tizen, браузер)
- Плейлист по логину **Xtream Codes**: сервер, логин и пароль. Каналы приходят с группами и логотипами, телегид того же аккаунта подключается сам.
- Мастер первого запуска короче: без вопросов про интересы и интернет.
- Логотип skmate слева сверху, «sk» в боковом меню, как в Android.
- **Демо:** [swensi17.github.io/skmate-iptv](https://swensi17.github.io/skmate-iptv/)

### Android TV
- Без изменений по сравнению с 2.1: обновление при входе с фоновой загрузкой и кнопкой «Установить».
