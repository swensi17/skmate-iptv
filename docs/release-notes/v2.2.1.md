## SkMate IPTV 2.2.1

Исправления Windows-версии: чёткая картинка и запуск на весь экран.

### Windows
- Интерфейс больше не размыт. Раньше экран 1920×1080 растягивался как картинка, а при масштабе Windows 125% или 150% и в окне нестандартного размера буквы расплывались. Теперь окно подгоняется масштабом самого Chromium, и текст рисуется в настоящем разрешении экрана.
- Приложение открывается на весь экран, как на телевизоре. F11 или Alt+Enter переключают на окно и обратно, выбор запоминается до следующего запуска.
- Ctrl+колёсико и Ctrl +/− больше не сбивают масштаб.
- Кто уже поставил 2.2.0, получит 2.2.1 сам: загрузка в фоне, затем окно «Установить / Позже».

### Веб-версия (LG webOS, Samsung Tizen, браузер)
- Экран ставится ровно по пикселям: в окне с нечётной шириной или высотой текст не расплывается.

### Android TV
- Без изменений по сравнению с 2.2.0.

### Файлы
| Файл | Для чего |

Установщик Windows не подписан сертификатом: при первом запуске «Подробнее» → «Выполнить в любом случае».
