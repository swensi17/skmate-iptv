## SkMate IPTV 2.2.2

Windows-версия: обычное окно с кнопками Windows и кнопка «На весь экран».

### Windows
- Приложение открывается развёрнутым окном с привычными кнопками «свернуть / развернуть / закрыть».
- Кнопка «На весь экран» в боковом меню (под «Настройками») и последней плиткой в нижней панели плеера. В полном экране та же кнопка называется «Обычное окно» и возвращает окно.
- F11 и Alt+Enter работают как раньше. Выбор запоминается до следующего запуска.
- Кто уже поставил 2.2.0 или 2.2.1, получит 2.2.2 сам: загрузка в фоне, затем окно «Установить / Позже».

### Веб-версия и Android TV
- Без изменений по сравнению с 2.2.1.

### Файлы
| Файл | Для чего |
|---|---|
| `SkMate-IPTV-Setup-2.2.2.exe` | Windows 10 и 11 (64 бита) |
| `SkMate-IPTV-v2.2.2-arm.apk` | Android TV, Google TV, Fire TV, приставки (arm) |
| `SkMate-IPTV-v2.2.2-x86_64.apk` | эмуляторы и приставки на Intel |
| `uz.skmate.iptv_2.2.2_all.ipk` | LG webOS 4+ (режим разработчика, `ares-install`) |
| `SkMate-IPTV-tizen-v2.2.2.wgt` | Samsung Tizen 4+ (подписать своим сертификатом Samsung в Tizen Studio) |
| `SkMate-IPTV-web-v2.2.2.zip` | веб-версия для любого сервера |

Установщик Windows не подписан сертификатом: при первом запуске «Подробнее» → «Выполнить в любом случае».
