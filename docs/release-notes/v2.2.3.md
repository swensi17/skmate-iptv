## SkMate IPTV 2.2.3

Исправление для Android TV: канал, открытый с главной, играет в обычном плеере.

### Android TV
- Канал, выбранный на главной, в поиске, в «Спорте», в напоминании или в «Продолжить просмотр», больше не открывает старый плеер с перемоткой и «Скоростью 1.0x» поверх пустого экрана и не вылетает по кругу.
- При включённом внешнем плеере («Настройки → Плеер → Внешний плеер») канал уходит только в него, встроенный плеер не открывается поверх. Если внешний плеер не смог открыть канал, канал сразу играет во встроенном.
- Предпросмотр наверху главной отпускает поток до запуска канала: у провайдеров, которые разрешают одно подключение, второй запрос больше не получает отказ.
- Канал прямого эфира всегда открывается с панелью эфира, даже если играет на запасном движке.
- Обновление приходит само: окно «Доступно обновление» при входе, загрузка в фоне, затем «Установить».

### Windows и веб-версия
- Без изменений по сравнению с 2.2.2.
