## skmate iptv 2.3.1

### обновления
- докачка с места обрыва, даже после перезапуска телевизора
- окно обновления по центру: версия, «что нового», «позже», «обновить сейчас», прогресс
- тихая проверка при запуске

### слабые телевизоры
- превью в каналах стабильнее и легче по памяти
- превью по умолчанию выключено на слабых устройствах
- меньше анимаций на слабых устройствах, ниже нагрузка

### файлы
- SkMate-IPTV-v2.3.1-arm.apk: android tv, google tv, fire tv, приставки
- SkMate-IPTV-v2.3.1-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для windows, lg webos и samsung tizen в разработке
