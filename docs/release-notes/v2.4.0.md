## skmate iptv 2.4.0

### слабые телевизоры
- лёгкий режим: без анимаций, интерфейс не нагружает процессор в простое
- быстрый и стабильный запуск, подбор телегида идёт в фоне
- плавный список каналов
- ровный эфир на медленном интернете

### приложение
- вес в два раза меньше
- обновление в одно нажатие, после установки кнопка «открыть»
- телегид обновляется тихо, без уведомлений
- номера групп по порядку: 1, 2, 3 … 10

### файлы
- SkMate-IPTV-v2.4.0-arm.apk: android tv, google tv, fire tv, приставки
- SkMate-IPTV-v2.4.0-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для windows, lg webos и samsung tizen в разработке
