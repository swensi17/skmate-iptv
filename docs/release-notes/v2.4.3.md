## skmate iptv 2.4.3

### приложение
- apk в два раза легче: отдельные сборки для 32 и 64 бит, на телевизоре нужно меньше места
- обновление внутри приложения скачивает сборку под процессор телевизора

### эфир
- свой плеер эфира: только нужные для тв модули, быстрее и легче
- канал в списке плеера включается по ok, если «предпросмотр эфира» выключен
- плавная смена каналов: чёрный экран до первого кадра нового канала
- картинка на весь экран при любой смене разрешения на канале
- точное определение каналов только со звуком

### файлы
- SkMate-IPTV-v2.4.3-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.4.3-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.4.3-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для windows, lg webos и samsung tizen в разработке
