## skmate iptv 2.6.1

### что нового
- большие плейлисты с телегидом больше не перегружают приставку при первой настройке: телегид загружается по очереди и записывается частями, памяти нужно почти вдвое меньше
- программа канала с одним архивом открывается на последней передаче
- кнопка «эфир» на шкале возвращает в прямой эфир, фокус остаётся на паузе
- своя функция на OK в эфире работает и при открытой информации
- на стыке передач информация сразу показывает новую передачу
- переключение канала всегда начинается с информации только для чтения
- удержание OK в программе не запускает передачу случайно
- «назад» сразу после закрытия программы закрывает панель
- значки «уже смотрел» не перечитываются на каждом шаге по списку
- цвет логотипа для белых и чёрных логотипов считается один раз

### файлы
- SkMate-IPTV-v2.6.1-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.6.1-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.6.1-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для lg webos и samsung tizen: github.com/swensi17/skmate-tv, для windows в разработке
