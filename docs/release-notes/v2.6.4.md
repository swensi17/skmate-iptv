## skmate iptv 2.6.4

### что нового
- программа по названию канала берётся точнее: «ТНТ4 HD» получает передачи именно «ТНТ4 HD», а не «ТНТ4» из другого телегида
- если канал есть в нескольких телегидах, при привязке учитывается порядок в «Источники EPG»: верхний важнее

### файлы
- SkMate-IPTV-v2.6.4-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.6.4-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.6.4-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для lg webos и samsung tizen: github.com/swensi17/skmate-tv, для windows в разработке
