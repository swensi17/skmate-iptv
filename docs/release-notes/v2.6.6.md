## skmate iptv 2.6.6

### что нового
- у каждого канала один телегид: расписания разных источников больше не смешиваются, берётся верхний в «Источники EPG», у которого есть передачи
- программа не расходится с эфиром при нескольких телегидах: каналы подбираются по названию только после загрузки всех телегидов, и номер канала из плейлиста не перебивается
- приставки, где с выключенным «аппаратным декодированием» приложение закрывалось: выключенный пункт снова включает программное декодирование, и оно стало легче
- после выхода из настроек пульт снова управляет списком каналов

### файлы
- SkMate-IPTV-v2.6.6-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.6.6-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.6.6-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для lg webos и samsung tizen: github.com/swensi17/skmate-tv, для windows в разработке
