## skmate iptv 2.6.8

### что нового
- программа не расходится с эфиром из-за старых привязок: один раз после обновления снимаются привязки по названию там, где по номеру канала из плейлиста уже есть программа; свои ручные привязки на таких каналах нужно сделать заново
- в настройках плеера можно скрыть «Недавно просмотренные» под эфиром

### файлы
- SkMate-IPTV-v2.6.8-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.6.8-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.6.8-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для lg webos и samsung tizen: github.com/swensi17/skmate-tv, для windows в разработке
