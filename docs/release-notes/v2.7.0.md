## skmate iptv 2.7.0

### что нового
- список каналов меняется сам, когда курсор стоит на категории, без OK: на экране каналов и в плеере по ◀
- после обновления плейлиста новые каналы сразу получают программу, не дожидаясь следующего запуска

### файлы
- SkMate-IPTV-v2.7.0-arm.apk: android tv, google tv, fire tv, любые arm-приставки
- SkMate-IPTV-v2.7.0-arm64.apk: приставки на 64-битной системе, приложение обновляется на неё само
- SkMate-IPTV-v2.7.0-x86_64.apk: эмуляторы и приставки на intel
- SkMate-IPTV.apk: та же arm-сборка, постоянная ссылка
- SHA256SUMS.txt: контрольные суммы

все сборки подписаны одним ключом, обновление ставится поверх
версии для lg webos и samsung tizen: github.com/swensi17/skmate-tv, для windows в разработке
