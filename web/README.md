# SkMate IPTV для LG webOS и Samsung Tizen

Веб-версия плеера для телевизоров LG и Samsung. Живёт в одном репозитории с Android-приложением, но полностью отдельно: свои пакеты, свои тесты, своя сборка. Дизайн, цвета, форма фокуса и логика поиска те же, что в Android.

## Устройство

Один обработчик пульта, никаких монолитов: каждый пакет делает одно дело и не знает про соседей сверх своего интерфейса.

| Пакет | Что внутри |
|---|---|
| `packages/core` | M3U-парсер и умный поиск (раскладки, транслит, опечатки). Порт `SmartSearch.kt`, тесты те же |
| `packages/player` | Интерфейс движка, лестница запасных вариантов (родной декодер ТВ, затем hls.js), без привязки к экрану |
| `packages/ui` | Токены дизайна, геометрическая навигация D-pad, адаптивные анимации, иконки Phosphor |
| `apps/tv` | Само приложение: экраны, строки (ru, en), настройки, пакеты webOS и Tizen |

Поддерживаются Chromium 53+ (webOS 4, Tizen 4): рядом с современным бандлом собирается старый. hls.js подгружается только когда родной декодер не справился.

## Команды

```bash
cd web
npm ci
npm run dev      # http://localhost:5173, 1920×1080
npm run check    # типы и тесты
npm run build    # apps/tv/dist
```

Проверка перед пушем (вместе с Android): `scripts/pre-push-check.sh`.

## Что готово и что дальше

Готово: оболочка, меню значками, группы и каналы в виртуальном списке (в DOM только видимые строки, прыжки по 10 каналов), поиск с индексом, плеер с лестницей движков и самовосстановлением hls.js, переключение каналов Вверх/Вниз с задержкой на «листание», панель плеера, экран ошибки, свои плейлисты по ссылке, избранное, тема по системе, адаптивные анимации, ru и en.

Проверено вживую на плейлисте из 3163 каналов: 21 из 24 каналов открылись, в среднем за 2,9 с (HD и 4K). Три канала Chrome на Mac не открыл: аппаратный декодер отверг один кадр потока (`PIPELINE_ERROR_DECODE`), сервер и сегменты в порядке. Причину любого канала показывает лог: `localStorage.setItem("skmate.hlsdebug", "1")`.

Телегид (XMLTV) работает по логике Android-приложения: гиды берутся из заголовка плейлиста (`url-tvg`), по провайдеру и общие; каналы связываются по `tvg-id` и по названию (нормализация плюс Джаро-Винклер с защитой по номерам каналов); гид читается потоком (в том числе `.xml.gz` на десятки мегабайт), хранятся только программы нужных каналов. На плейлисте из 3163 каналов связано 3150.

Дальше: история просмотра, зеркала каналов, сортировка и подборки, пакеты `.ipk` и `.wgt`, проверка на настоящих телевизорах (там воспроизводит родной декодер ТВ, hls.js только запасной).

Ограничение веба: браузер не отдаёт плейлисты с серверов без заголовков CORS. На телевизоре такие плейлисты откроются через небольшой прокси, это следующий шаг.
