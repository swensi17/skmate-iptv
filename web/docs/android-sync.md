## только android, не переносится

- вылет при выключенном аппаратном декодировании (2.6.5)
- декодер libvlc без прямого вывода (2.6.3)
- «аппаратное декодирование» для эфира libvlc (2.6.2)
- задержка звука в инструментах (в вебе нет задержки звука); «звук» по-прежнему при нескольких дорожках
- в панели плеера программа под картинкой уже была с 2.5.3, отдельная боковая не нужна
- вылет при разворачивании канала (r8, 2.5.9)
- боковое меню без рывка (2.5.5): у веба своя анимация
