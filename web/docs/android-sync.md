## ждёт переноса

сверено до `f65e6f9` (релиз 2.6.1), перенесено пока только то, что ниже в «уже как в android».

из 2.6.0, в вебе этих экранов нет:
- [ ] кнопки в эфире как на тв: всплывающее инфо не мешает ▲ ▼, ok открывает управление
- [ ] ряд «недавно просмотренные» под инфо: телегид, история, до 10 каналов в карточках цвета логотипа
- [ ] строка перемотки на шкале |◀ ◀◀ ⏸ ▶▶ ▶|, эфир и запись, время передачи
- [ ] программа канала по ▶ на экране каналов и в панели плеера: дни, описание, постер, архив по ok
- [ ] в панели плеера с программой видео меньше, под ним постер и эфир
- [ ] без телепрограммы по центру значок и надпись
- [ ] значок «уже смотрел» у каналов в списке
- [ ] в инструментах «звук» всегда, «качество» при вариантах потока
- [ ] удержание ok на передаче с постером: постер на весь экран
- [ ] «назад» из ряда закрывает всё одним нажатием

из 2.6.1, зависит от экранов 2.6.0:
- [ ] кнопка «эфир» на шкале, фокус остаётся на паузе
- [ ] своя функция на ok при открытом инфо (в вебе нет настройки своей функции ok)
- [ ] удержание ok в программе не запускает передачу; «назад» после закрытия программы закрывает панель
- [ ] программа канала с одним архивом открывается на последней передаче

## уже как в android 2.6.1

- телегид: источники читаются по очереди, передачи пишутся в indexeddb пачками по 5000, повторы отсекаются при
  чтении без строк-ключей; весь гид в памяти не держится (только при отсутствии indexeddb, окно 12 ч)
- стык передач: текущая передача считается заново каждую секунду, на стыке сразу новая (тест в `epg.test.ts`)
